# Симулятор проектирования пешеходной дорожной сети

Игра-головоломка, в которой игрок строит и меняет сеть пешеходных дорожек,
а затем наблюдает, как виртуальные пешеходы выбирают маршруты с учётом
своих предпочтений. Учебный проект по алгоритмизации и геймдеву.


## Возможности

- в работе - Сравнить аналоги (Cities: Skylines, Mini Metro, TheoTown, STATIONflow);

- в планах - Исследовать алгоритмы поиска пути (A*, flow field);

- в планах - Собрать и проанализировать данные о поведении пешеходов;

- в планах - Предобработка карты для алгоритмов навигации;

- в планах - Построение пешеходной дорожной сети в игровом пространстве;

- в планах - Имитация движения пешеходов по созданным маршрутам;

- в планах - Учёт предпочтений пешеходов при выборе пути;

- в планах - Начисление очков за качество маршрута;

- в планах - Уровни-головоломки с ограниченным бюджетом дорожек.
